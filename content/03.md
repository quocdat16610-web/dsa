# Tìm kiếm nhị phân

## 1. Ý tưởng
Trên một miền **đơn điệu** (dãy đã sắp xếp, hoặc hàm đúng/sai dạng `F F F T T T`), mỗi bước so sánh với phần tử giữa giúp loại bỏ một nửa miền tìm kiếm. Độ phức tạp `O(log n)`.

## 2. Mẫu code an toàn: tìm vị trí `true` đầu tiên
```cpp
// check(x) có dạng F F F ... T T T trên [lo, hi]; giả sử check(hi) = true
long long lo = L, hi = R;
while (lo < hi) {
    long long mid = lo + (hi - lo) / 2;   // tránh tràn số
    if (check(mid)) hi = mid;            // mid có thể là đáp án
    else lo = mid + 1;
}
// lo là vị trí true đầu tiên
```
Tìm `true` **cuối cùng** (dạng `T T T F F`): dùng `mid = lo + (hi - lo + 1) / 2`, nếu đúng thì `lo = mid`, sai thì `hi = mid - 1` — chú ý `+1` để không lặp vô hạn.

## 3. Thư viện C++
- `lower_bound(a, a + n, x)`: vị trí đầu tiên có `a[i] ≥ x`.
- `upper_bound(a, a + n, x)`: vị trí đầu tiên có `a[i] > x`.
- Số phần tử bằng `x`: `upper_bound - lower_bound`. Số phần tử trong `[L, R]`: `upper_bound(R) - lower_bound(L)`.

## 4. Chặt nhị phân đáp án
Khi bài hỏi "giá trị nhỏ nhất/lớn nhất sao cho ..." và ta **kiểm tra** được một giá trị `x` có thoả mãn không (thường bằng tham lam `O(n)`), đồng thời tính chất thoả mãn là đơn điệu theo `x`:
- Nhà máy: sau `t` giây làm được `Σ t / a_i` sản phẩm — tăng theo `t`.
- Chia dãy thành `k` đoạn, tổng lớn nhất nhỏ nhất: kiểm tra "mỗi đoạn ≤ m" bằng tham lam.
- Chuồng bò: kiểm tra "đặt được `c` con với khoảng cách ≥ d".

Tổng độ phức tạp `O(n log(miền giá trị))`.

## 5. Tìm kiếm nhị phân trên số thực
Lặp cố định ~100 lần (mỗi lần chia đôi khoảng), không dùng điều kiện `hi - lo > eps` dễ lặp vô hạn do sai số.
```cpp
double lo = 0, hi = 1e6;
for (int it = 0; it < 100; it++) { double m = (lo + hi) / 2; if (f(m) < C) lo = m; else hi = m; }
```

## Lỗi thường gặp
- `mid = (lo + hi) / 2` tràn khi `lo + hi > 2^63`; cận trên quá nhỏ (ví dụ `min(a) * t` có thể tới `10^18`).
- Lặp vô hạn khi dùng `lo = mid` với `mid` làm tròn xuống.
- Hàm kiểm tra không thực sự đơn điệu.
