# Map – Set – Heap

## 1. `set` và `multiset`
Cây nhị phân tìm kiếm cân bằng (đỏ-đen): các phần tử luôn **có thứ tự**, thêm/xoá/tìm `O(log n)`.
```cpp
set<int> s; s.insert(5); s.erase(5); s.count(5);
auto it = s.lower_bound(x);       // phần tử nhỏ nhất ≥ x
if (it != s.begin()) --it;        // phần tử lớn nhất < x
multiset<int> ms; ms.erase(ms.find(x));   // xoá MỘT phần tử x (ms.erase(x) xoá tất cả!)
*ms.begin(); *ms.rbegin();        // nhỏ nhất, lớn nhất
```

## 2. `map` và `unordered_map`
`map<K, V>` có thứ tự, `O(log n)`; `unordered_map` là bảng băm, trung bình `O(1)` nhưng có thể bị test chống hash làm chậm.
```cpp
map<int,int> cnt; for (int x : a) cnt[x]++;
for (auto [v, c] : cnt) cout << v << ' ' << c << '\n';   // duyệt theo khoá tăng dần
```

## 3. Heap — `priority_queue`
Cây nhị phân đầy đủ, nút cha ≥ nút con (max-heap). `push`, `pop` `O(log n)`, `top` `O(1)`.
```cpp
priority_queue<int> pq;                                 // max-heap
priority_queue<int, vector<int>, greater<int>> mn;      // min-heap
priority_queue<pair<long long,int>> pq2;                // so sánh theo first rồi second
```

## 4. Tham lam với heap
- **Nối dây (Huffman):** luôn ghép hai sợi ngắn nhất.
- **Lập lịch có hạn chót:** xét việc theo hạn chót tăng dần, giữ min-heap lợi nhuận; khi số việc vượt hạn thì bỏ việc lời ít nhất.
- **Phòng khách sạn:** sắp xếp theo giờ đến, min-heap lưu giờ trả phòng.

## 5. Hai heap — trung vị động
Max-heap chứa nửa nhỏ, min-heap chứa nửa lớn; luôn cân bằng sao cho kích thước chênh nhau ≤ 1. Trung vị là đỉnh max-heap.
Muốn **xoá** phần tử bất kỳ (cửa sổ trượt) thì dùng hai `multiset` thay cho heap.

## Lỗi thường gặp
- `multiset::erase(value)` xoá **mọi** phần tử bằng value.
- Gọi `*s.begin()` hoặc `pq.top()` khi rỗng.
- `map[key]` tự tạo khoá nếu chưa có — dùng `count`/`find` khi chỉ muốn kiểm tra.
