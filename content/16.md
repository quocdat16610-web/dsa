# Cây phân đoạn, cây Fenwick, đường quét

## 1. Cây Fenwick (BIT)
Cập nhật điểm và tổng tiền tố đều `O(log n)`, code rất ngắn:
```cpp
long long bit[N];
void add(int i, long long v) { for (; i <= n; i += i & -i) bit[i] += v; }
long long sum(int i) { long long s = 0; for (; i > 0; i -= i & -i) s += bit[i]; return s; }
```
- Cộng đoạn, hỏi điểm: BIT trên mảng hiệu.
- Cộng đoạn, tổng đoạn: hai BIT.
- Đếm nghịch thế, phần tử thứ k (nhảy nhị phân trên BIT).

## 2. Cây phân đoạn (segment tree)
Mỗi nút quản lý một đoạn, lưu kết quả của đoạn đó; nút `k` có hai con `2k`, `2k+1`.
```cpp
void update(int k, int l, int r, int pos, int val) {
    if (l == r) { t[k] = val; return; }
    int m = (l + r) / 2;
    if (pos <= m) update(2*k, l, m, pos, val); else update(2*k+1, m+1, r, pos, val);
    t[k] = min(t[2*k], t[2*k+1]);
}
int query(int k, int l, int r, int ql, int qr) {
    if (qr < l || r < ql) return INF;
    if (ql <= l && r <= qr) return t[k];
    int m = (l + r) / 2;
    return min(query(2*k, l, m, ql, qr), query(2*k+1, m+1, r, ql, qr));
}
```
Lưu được thông tin phức tạp: (tổng, max tiền tố, max hậu tố, max đoạn con) để trả lời "đoạn con lớn nhất" có cập nhật.

**Đi xuống trên cây:** tìm vị trí đầu tiên có giá trị ≥ g (đặt phòng khách sạn) trong `O(log n)`.

## 3. Lan truyền lười (lazy propagation)
Cập nhật cả đoạn: gán nhãn `lazy` cho các nút phủ trọn đoạn, chỉ **đẩy xuống** con khi cần đi sâu hơn.
```cpp
void push(int k, int l, int r) { if (lz[k]) { apply(2*k, lz[k]); apply(2*k+1, lz[k]); lz[k] = 0; } }
```
Nhãn có thể là: cộng thêm, gán giá trị, đảo bit, cấp số cộng (đầu, công sai)...

## 4. Đường quét (sweep line)
Biến bài toán hình học/khoảng thời gian thành dãy **sự kiện** đã sắp xếp; quét qua và duy trì cấu trúc dữ liệu:
- nhiều khách nhất cùng lúc: sự kiện `+1`/`-1`;
- giao điểm đoạn ngang–dọc: BIT trên toạ độ `y`;
- diện tích hợp hình chữ nhật: cây phân đoạn lưu độ dài được phủ.

## 5. Offline và nén số
Đọc hết truy vấn trước, sắp xếp lại cho tiện xử lý (số giá trị phân biệt trên đoạn, đếm điểm trong hình chữ nhật). Nén toạ độ: `sort + unique + lower_bound`.

## Lỗi thường gặp
- Mảng cây phân đoạn cần `4n` phần tử.
- Quên `push` trước khi đi xuống ở cả update lẫn query.
