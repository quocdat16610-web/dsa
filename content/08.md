# Quy hoạch động đếm

## 1. Nguyên tắc
- **Quy tắc cộng:** các trường hợp rời nhau thì cộng số cách.
- **Quy tắc nhân:** các bước độc lập liên tiếp thì nhân số cách.
- Kết quả thường rất lớn ⇒ lấy modulo `10^9 + 7` **sau mỗi phép cộng/nhân**.

## 2. Ví dụ kinh điển
- **Leo cầu thang / tung xúc xắc:** `dp[i] = dp[i-1] + ... + dp[i-k]`.
- **Đường đi trên lưới:** `dp[i][j] = dp[i-1][j] + dp[i][j-1]` (bỏ qua ô cấm).
- **Lát gạch 2×n:** `f(n) = f(n-1) + f(n-2)` (Fibonacci!).
- **Phân hoạch số:** đổi tiền không thứ tự với mệnh giá `1..n`.

## 3. Tránh đếm trùng
Đếm **dãy** (thứ tự quan trọng) và **tập hợp** (không quan trọng) khác nhau ở thứ tự vòng lặp:
```cpp
// có thứ tự (2+3 khác 3+2)
for (int v = 1; v <= x; v++) for (int c : coins) if (c <= v) dp[v] += dp[v - c];
// không thứ tự
for (int c : coins) for (int v = c; v <= x; v++) dp[v] += dp[v - c];
```

## 4. Tối ưu bằng tổng tiền tố
Khi `dp[i][j] = Σ_{t=0..k} dp[i-1][j-t]`, tính tổng tiền tố của hàng `i-1` để mỗi ô `O(1)` (chia kẹo có giới hạn, hoán vị có k nghịch thế, hoán vị theo mẫu `<>`).

## 5. QHĐ chữ số (digit DP)
Đếm số `x ∈ [0, N]` thoả tính chất về chữ số: duyệt chữ số từ trái sang phải, trạng thái gồm
`(vị trí, thông tin cần nhớ, tight = đang bằng tiền tố của N?, started = đã có chữ số khác 0?)`.
```cpp
long long go(int pos, int prev, bool tight, bool started) {
    if (pos == len) return 1;
    // memo theo (pos, prev) khi !tight
    int lim = tight ? d[pos] : 9; long long res = 0;
    for (int x = 0; x <= lim; x++) { /* kiểm tra điều kiện */ res += go(pos + 1, x, tight && x == lim, started || x); }
    return res;
}
```
Đáp án đoạn `[a, b]` = `f(b) - f(a - 1)`.

## 6. Kết hợp tổ hợp
Đường đi tự do từ `(1,1)` tới `(x,y)` là `C(x+y-2, x-1)`. Với lưới lớn có ít ô cấm, dùng bao hàm loại trừ theo các ô cấm đã sắp xếp.

## Lỗi thường gặp
- Quên modulo hoặc modulo số âm sau phép trừ: `(a - b + MOD) % MOD`.
- Đếm cả trường hợp rỗng (nhớ trừ 1 nếu đề yêu cầu khác rỗng).
