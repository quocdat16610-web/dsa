# DSU và cây khung nhỏ nhất

## 1. Disjoint Set Union
Quản lý các tập rời nhau với hai thao tác: `find(x)` (đại diện của tập chứa `x`) và `unite(a, b)`.
```cpp
int par[N], sz[N];
int find(int x) { return par[x] == x ? x : par[x] = find(par[x]); }   // nén đường đi
bool unite(int a, int b) {
    a = find(a); b = find(b);
    if (a == b) return false;
    if (sz[a] < sz[b]) swap(a, b);                                     // hợp theo kích thước
    par[b] = a; sz[a] += sz[b]; return true;
}
```
Với cả hai tối ưu, mỗi thao tác gần như `O(1)` (`O(α(n))`).

## 2. Kruskal
Sắp xếp cạnh tăng dần theo trọng số, thêm cạnh nếu nối hai thành phần khác nhau. `O(m log m)`.
```cpp
sort(edges.begin(), edges.end());
for (auto [w, u, v] : edges) if (unite(u, v)) total += w;
```
Cây khung nhỏ nhất cũng tối ưu **cạnh lớn nhất** (bottleneck). Dừng sớm khi còn `k` thành phần ⇒ rừng `k` cây nhỏ nhất.

## 3. Prim
Giống Dijkstra nhưng `d[v]` là trọng số cạnh nhỏ nhất nối `v` với cây hiện tại. Bản `O(n²)` không heap rất tốt cho đồ thị **dày** (ma trận đầy đủ, khoảng cách giữa các điểm).

## 4. DSU mở rộng
- **DSU có trọng số:** lưu `d[x] = val[x] - val[par[x]]`; khi nén đường đi thì cộng dồn — trả lời "hiệu giữa hai phần tử".
- **DSU parity:** kiểm tra đồ thị hai phía khi thêm cạnh online.
- **Đảo ngược thời gian:** DSU không xoá được, nhưng nếu biết trước thứ tự xoá thì thêm ngược lại.
- **DSU "nhảy":** `nxt[x]` = vị trí chưa xử lý tiếp theo (sơn hàng rào).

## 5. Đỉnh ảo
"Đào giếng tốn `c_i` hoặc nối ống" ⇒ thêm đỉnh 0 nối tới mọi nhà với trọng số `c_i`, rồi tìm MST.

## Lỗi thường gặp
- Đệ quy `find` quá sâu khi không có hợp theo kích thước.
- Quên kiểm tra đồ thị liên thông (MST không tồn tại).
