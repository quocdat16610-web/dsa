# Tổng tiền tố & mảng hiệu

## 1. Mảng cộng dồn (prefix sum)
`p[0] = 0`, `p[i] = p[i-1] + a[i]`. Khi đó tổng đoạn `[l, r]` là `p[r] - p[l-1]` — mỗi truy vấn `O(1)` sau khi tiền xử lý `O(n)`.

```cpp
vector<long long> p(n + 1, 0);
for (int i = 1; i <= n; i++) p[i] = p[i - 1] + a[i];
// tổng a[l..r]
long long sum = p[r] - p[l - 1];
```
Ý tưởng "tiền tố" dùng được với mọi phép toán **có phép ngược**: cộng (trừ), XOR (XOR), nhân modulo nguyên tố (nhân nghịch đảo)... Không dùng được cho `min`, `max`, `gcd`.

## 2. Mảng hiệu (difference array)
Muốn cộng `x` vào mọi phần tử `a[l..r]` nhiều lần rồi mới hỏi kết quả cuối:
```cpp
d[l] += x; d[r + 1] -= x;      // mỗi thao tác O(1)
// cuối cùng: cộng dồn d để biết lượng cộng vào từng vị trí
for (int i = 1; i <= n; i++) d[i] += d[i - 1], a[i] += d[i];
```
Mảng hiệu là "phép ngược" của mảng cộng dồn.

## 3. Tiền tố 2 chiều
```
P[i][j] = a[i][j] + P[i-1][j] + P[i][j-1] - P[i-1][j-1]
tổng(x1,y1,x2,y2) = P[x2][y2] - P[x1-1][y2] - P[x2][y1-1] + P[x1-1][y1-1]
```
Mảng hiệu 2D: `D[x1][y1] += v; D[x1][y2+1] -= v; D[x2+1][y1] -= v; D[x2+1][y2+1] += v`.

## 4. Đếm đoạn con bằng tiền tố + map
Đoạn `(l, r]` có tổng `k` ⇔ `p[r] - p[l] = k` ⇔ `p[l] = p[r] - k`. Duyệt `r`, đếm số lần `p[r] - k` đã xuất hiện:
```cpp
map<long long,int> cnt; cnt[0] = 1; long long s = 0, ans = 0;
for (int i = 1; i <= n; i++) { s += a[i]; ans += cnt[s - k]; cnt[s]++; }
```
Biến thể: tổng chia hết cho `k` (đếm theo số dư), đoạn có số 0 và số 1 bằng nhau (đổi 0 thành −1).

## 5. Kỹ thuật đóng góp
Thay vì duyệt mọi đoạn, hỏi "mỗi phần tử góp vào bao nhiêu đoạn?". `a[i]` thuộc đúng `i · (n - i + 1)` đoạn con.

## Lỗi thường gặp
- Dùng `int` cho mảng tiền tố — tổng có thể vượt `2·10^9`.
- Lệch chỉ số: quy ước rõ mảng bắt đầu từ 0 hay 1. Nên dùng `p` có `n + 1` phần tử với `p[0] = 0`.
- Mảng hiệu cần kích thước `n + 2` (vì truy cập `d[r + 1]`).
