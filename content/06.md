# Đệ quy – Quay lui, Bitwise

## 1. Đệ quy
Hàm gọi lại chính nó với bài toán nhỏ hơn, phải có **điểm dừng**.
```cpp
long long fact(int n) { return n <= 1 ? 1 : n * fact(n - 1); }
```
Mỗi lời gọi chiếm một khung trên ngăn xếp — đệ quy quá sâu (~10^5–10^6 tầng) có thể tràn ngăn xếp.

## 2. Quay lui (backtracking)
Xây dựng lời giải từng bước, thử mọi lựa chọn hợp lệ ở mỗi bước, "quay lui" để thử lựa chọn khác.
```cpp
int n, x[20]; bool used[20];
void gen(int i) {                 // sinh hoán vị
    if (i == n) { /* in x */ return; }
    for (int v = 1; v <= n; v++) if (!used[v]) {
        used[v] = true; x[i] = v;
        gen(i + 1);
        used[v] = false;          // hoàn tác
    }
}
```
Khuôn mẫu: **chọn → đệ quy → bỏ chọn**. Các bài: xâu nhị phân, tổ hợp, tập con có tổng S, N quân hậu, dãy ngoặc đúng, phân tích số.

**Nhánh cận:** nếu từ trạng thái hiện tại chắc chắn không tốt hơn kết quả đã có thì dừng nhánh đó.

## 3. N quân hậu
Đặt từng hàng; đánh dấu cột, đường chéo chính (`i - j + n`) và chéo phụ (`i + j`). Mỗi bước `O(1)` kiểm tra.

## 4. Toán tử bit
| Phép | Ý nghĩa |
|---|---|
| `a & b`, `a \| b`, `a ^ b` | AND, OR, XOR từng bit |
| `x << k`, `x >> k` | nhân/chia `2^k` |
| `x >> i & 1` | bit thứ `i` |
| `x \| (1 << i)`, `x & ~(1 << i)`, `x ^ (1 << i)` | bật / tắt / đảo bit `i` |
| `x & (x - 1)` | xoá bit 1 thấp nhất |
| `x & -x` | bit 1 thấp nhất |
| `__builtin_popcount(x)` | số bit 1 (`popcountll` cho `long long`) |

Tính chất XOR: `x ^ x = 0`, `x ^ 0 = x`, giao hoán, kết hợp — tìm "số lẻ loi" chỉ cần XOR tất cả.

## 5. Duyệt tập con bằng bitmask
```cpp
for (int mask = 0; mask < (1 << n); mask++)
    for (int i = 0; i < n; i++) if (mask >> i & 1) { /* phần tử i được chọn */ }
```
Duyệt tập con của `mask`: `for (int s = mask; s; s = (s - 1) & mask)`.

## 6. Meet in the middle
`n = 40` thì `2^40` quá lớn, nhưng `2^20` thì được: chia đôi, liệt kê tổng tập con của mỗi nửa, rồi ghép bằng sắp xếp + tìm kiếm nhị phân/hai con trỏ.

## Lỗi thường gặp
- `1 << 40` tràn `int` — dùng `1LL << 40`.
- Thứ tự ưu tiên toán tử: `x & 1 == 0` nghĩa là `x & (1 == 0)`! Luôn thêm ngoặc.
- Quên hoàn tác trạng thái khi quay lui.
