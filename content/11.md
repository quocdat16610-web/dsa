# Cây DFS, đỉnh khớp và cầu

## 1. Cây DFS và tin/tout
Khi DFS, ghi thời điểm vào `tin[u]` và thời điểm ra `tout[u]`. Các cạnh DFS đi qua tạo thành **cây DFS**; với đồ thị vô hướng, các cạnh còn lại đều nối một đỉnh với **tổ tiên** của nó (cạnh ngược).
`u` là tổ tiên của `v` ⇔ `tin[u] ≤ tin[v] ≤ tout[u]`.

## 2. Bài toán trên cây
- **Kích thước cây con:** `sz[u] = 1 + Σ sz[con]`.
- **Đường kính:** DFS từ đỉnh bất kỳ tới đỉnh xa nhất `a`, rồi DFS từ `a` tới đỉnh xa nhất `b`.
- **Đổi gốc (rerooting):** tính đáp án cho gốc 1, rồi chuyển gốc sang con trong `O(1)`: tổng khoảng cách `ans[u] = ans[p] + n - 2·sz[u]`.
- **Trọng tâm:** đỉnh mà xoá đi thì mọi phần còn lại có ≤ `n/2` đỉnh.

## 3. low-link
`low[u]` = `tin` nhỏ nhất tới được từ cây con của `u` bằng cách đi các cạnh cây xuống rồi **tối đa một** cạnh ngược.
```cpp
void dfs(int u, int pe) {               // pe: chỉ số cạnh từ cha (xử lý cạnh song song)
    tin[u] = low[u] = ++timer;
    for (auto [v, id] : adj[u]) {
        if (id == pe) continue;
        if (tin[v]) low[u] = min(low[u], tin[v]);           // cạnh ngược
        else {
            dfs(v, id);
            low[u] = min(low[u], low[v]);
            if (low[v] > tin[u]) /* cạnh (u,v) là CẦU */;
            if (low[v] >= tin[u] && pe != -1) /* u là KHỚP */;
        }
    }
    // gốc DFS là khớp ⇔ có ≥ 2 con trong cây DFS
}
```

## 4. Ý nghĩa
- **Cầu:** cạnh mà xoá đi làm tăng số thành phần liên thông ⇔ cây con của `v` không có cạnh ngược vượt lên trên `u`.
- **Khớp:** đỉnh mà xoá đi làm tăng số thành phần liên thông.
- Xoá hết cầu ⇒ các **thành phần song liên thông cạnh**; nén mỗi thành phần thành một đỉnh ta được **cây cầu**.
- Định lý Robbins: định hướng được mọi cạnh để đồ thị liên thông mạnh ⇔ liên thông và không có cầu.

## Lỗi thường gặp
- Dùng "đỉnh cha" thay vì "cạnh cha" ⇒ sai khi có cạnh song song.
- Đệ quy sâu `10^5` tầng — tăng stack hoặc cài DFS lặp.
- Quên xử lý riêng gốc DFS khi tìm khớp.
