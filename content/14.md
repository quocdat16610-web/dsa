# Max, Min trên đoạn tịnh tiến (deque & ngăn xếp đơn điệu)

## 1. Ngăn xếp đơn điệu
Tìm phần tử **lớn hơn gần nhất bên phải** cho mọi vị trí trong `O(n)`:
```cpp
stack<int> st; // chứa chỉ số, giá trị giảm dần từ đáy lên đỉnh
for (int i = n - 1; i >= 0; i--) {
    while (!st.empty() && a[st.top()] <= a[i]) st.pop();
    nxt[i] = st.empty() ? -1 : st.top();
    st.push(i);
}
```
Mỗi phần tử vào/ra ngăn xếp một lần. Ứng dụng: hình chữ nhật lớn nhất trong biểu đồ, hứng nước mưa, nhìn thấy bao nhiêu người.

## 2. Kỹ thuật đóng góp
`a[i]` là min của bao nhiêu đoạn con? Gọi `L` = khoảng cách tới phần tử nhỏ hơn bên trái, `R` = tới phần tử nhỏ hơn hoặc bằng bên phải ⇒ `L · R` đoạn. Một bên dùng `<`, bên kia `≤` để không đếm trùng.

## 3. Deque đơn điệu — max cửa sổ trượt
```cpp
deque<int> dq;  // chỉ số, giá trị giảm dần
for (int i = 0; i < n; i++) {
    while (!dq.empty() && a[dq.back()] <= a[i]) dq.pop_back();
    dq.push_back(i);
    if (dq.front() <= i - k) dq.pop_front();       // ra khỏi cửa sổ
    if (i >= k - 1) cout << a[dq.front()] << ' ';
}
```
Phần tử bị bỏ ở cuối vì "có phần tử mới hơn và lớn hơn" — nó không bao giờ là max nữa.

## 4. Ứng dụng
- Max/min cửa sổ 2D: trượt theo hàng rồi theo cột.
- Đoạn con có tổng lớn nhất với độ dài trong `[A, B]`: deque giữ min tiền tố.
- Đoạn ngắn nhất có tổng ≥ k khi có số âm.
- **Tối ưu QHĐ:** `dp[i] = a[i] + max(dp[i-k..i-1])` từ `O(nk)` xuống `O(n)`.

## Lỗi thường gặp
- Lưu giá trị thay vì chỉ số ⇒ không biết khi nào phần tử ra khỏi cửa sổ.
- Nhầm điều kiện `<` / `≤` khi có phần tử bằng nhau.
