# Đường đi ngắn nhất

## 1. Dijkstra (trọng số không âm)
```cpp
vector<long long> d(n + 1, INF); d[s] = 0;
priority_queue<pair<long long,int>, vector<pair<long long,int>>, greater<>> pq; pq.push({0, s});
while (!pq.empty()) {
    auto [du, u] = pq.top(); pq.pop();
    if (du != d[u]) continue;                 // bản ghi cũ
    for (auto [v, w] : adj[u]) if (du + w < d[v]) { d[v] = du + w; pq.push({d[v], v}); }
}
```
`O((n + m) log n)`. Tham lam đúng vì khi một đỉnh được lấy ra với khoảng cách nhỏ nhất, không đường nào khác (qua cạnh không âm) có thể ngắn hơn.

**Biến thể:** đa nguồn; trên lưới; trên **đồ thị trạng thái** `(đỉnh, đã dùng phiếu?)`, `(đỉnh, số vé miễn phí đã dùng)`; đếm số đường ngắn nhất; k đường ngắn nhất (cho phép mỗi đỉnh lấy ra `k` lần).

## 2. Bellman-Ford (có trọng số âm)
Lặp `n - 1` lần, mỗi lần nới lỏng tất cả cung. Nếu lần thứ `n` vẫn nới lỏng được ⇒ có **chu trình âm**. `O(n·m)`.
```cpp
for (int it = 1; it < n; it++) for (auto [u, v, w] : edges) if (d[u] != INF && d[u] + w < d[v]) d[v] = d[u] + w;
```

## 3. Floyd-Warshall (mọi cặp)
```cpp
for (int k = 1; k <= n; k++) for (int i = 1; i <= n; i++) for (int j = 1; j <= n; j++)
    d[i][j] = min(d[i][j], d[i][k] + d[k][j]);
```
`O(n³)`, vòng `k` ở **ngoài cùng**. Ý nghĩa: sau vòng `k`, `d[i][j]` là đường ngắn nhất chỉ đi qua các đỉnh trung gian `1..k`.
Biến thể: minimax (`max` thay `+`), chu trình ngắn nhất, thêm đỉnh dần.

## 4. Đồ thị đường đi ngắn nhất
Dijkstra từ `s` và từ `t`. Cạnh `(u, v, w)` nằm trên **một** đường ngắn nhất ⇔ `ds[u] + w + dt[v] = ds[t]`.

## Chọn thuật toán nào?
| Tình huống | Thuật toán |
|---|---|
| Không trọng số | BFS |
| Trọng số 0/1 | BFS 0-1 |
| Trọng số không âm | Dijkstra |
| Có trọng số âm | Bellman-Ford (hoặc QHĐ nếu là DAG) |
| Mọi cặp, `n ≤ 500` | Floyd |

## Lỗi thường gặp
- Dijkstra với cạnh âm cho kết quả sai.
- `INF + w` bị tràn; `INF` quá nhỏ (dùng `1e18` cho `long long`).
- Quên dòng `if (du != d[u]) continue;` ⇒ chậm.
