# Sàng nguyên tố & các bài toán số học

## 1. Số nguyên tố
Số nguyên tố là số tự nhiên lớn hơn 1 chỉ có hai ước là 1 và chính nó. Nếu `n` là hợp số thì `n` có một ước `d ≤ √n`, nên chỉ cần thử chia tới `√n`.

```cpp
bool isPrime(long long n) {
    if (n < 2) return false;
    for (long long d = 2; d * d <= n; d++)
        if (n % d == 0) return false;
    return true;
}
```
Độ phức tạp `O(√n)`. Viết `d * d <= n` thay vì `d <= sqrt(n)` để tránh sai số số thực.

## 2. Sàng Eratosthenes
Đánh dấu mọi số là nguyên tố, rồi với mỗi số nguyên tố `i`, gạch bỏ các bội `i*i, i*i + i, ...` (các bội nhỏ hơn `i*i` đã bị gạch bởi ước nhỏ hơn).

```cpp
const int N = 1000000;
vector<bool> isP(N + 1, true);
void sieve() {
    isP[0] = isP[1] = false;
    for (int i = 2; (long long)i * i <= N; i++)
        if (isP[i])
            for (int j = i * i; j <= N; j += i) isP[j] = false;
}
```
Độ phức tạp `O(n log log n)` — gần như tuyến tính.

**Sàng ước nguyên tố nhỏ nhất (SPF):** lưu `spf[x]` thay vì true/false. Khi đó phân tích `x` chỉ mất `O(log x)`:
```cpp
while (x > 1) { int p = spf[x]; int k = 0; while (x % p == 0) x /= p, k++; /* p^k */ }
```

**Sàng đoạn** `[L, R]` với `R` tới `10^12`: sàng các số nguyên tố `≤ √R`, rồi gạch bội của chúng trong mảng độ dài `R - L + 1`.

## 3. Ước số, phân tích thừa số
Nếu `n = p1^a1 · p2^a2 · ... · pk^ak` thì:
- số ước: `(a1 + 1)(a2 + 1)...(ak + 1)`;
- tổng ước: `Π (p^(a+1) - 1) / (p - 1)`;
- `φ(n) = n · Π (1 - 1/p)`.

## 4. UCLN, BCNN
`gcd(a, b) = gcd(b, a mod b)`, `gcd(a, 0) = a`. Trong C++ dùng `__gcd` hoặc `std::gcd` (C++17).
`lcm(a, b) = a / gcd(a, b) * b` — **chia trước rồi nhân** để tránh tràn số.

## 5. Luỹ thừa nhanh và nghịch đảo modulo
```cpp
long long power(long long a, long long b, long long m) {
    long long r = 1; a %= m;
    while (b) { if (b & 1) r = r * a % m; a = a * a % m; b >>= 1; }
    return r;
}
```
Với `p` nguyên tố và `a` không chia hết cho `p`: `a^(p-1) ≡ 1 (mod p)` (Fermat nhỏ) ⇒ nghịch đảo `a^(-1) ≡ a^(p-2)`.

**Tổ hợp:** tính trước `fact[i]` và `inv[i] = fact[i]^(-1)`, khi đó `C(n, k) = fact[n] · inv[k] · inv[n-k]`. Tính `inv` ngược từ `inv[N] = power(fact[N], p-2)` và `inv[i-1] = inv[i] · i`.

## 6. Bao hàm - loại trừ
Số số trong `[1, n]` chia hết cho ít nhất một trong `p1..pk` = `Σ n/pi − Σ n/(pi·pj) + Σ n/(pi·pj·pl) − ...` Duyệt tập con bằng bitmask.

## Lỗi thường gặp
- Quên `long long` (ví dụ `i * i` tràn `int` khi `i ≈ 50000`).
- Sàng tới `10^7` bằng `vector<int>` tốn 40MB — dùng `vector<bool>` hoặc `bitset`.
- Số 1 **không** phải số nguyên tố; số 2 là số nguyên tố chẵn duy nhất.
- Lấy modulo số âm trong C++ cho kết quả âm: dùng `((x % m) + m) % m`.
