# LCA và Euler tour

## 1. Nhảy nhị phân
`up[j][v]` = tổ tiên thứ `2^j` của `v`; `up[j][v] = up[j-1][ up[j-1][v] ]`. Tổ tiên thứ `k`: duyệt các bit của `k`.

## 2. LCA bằng nhảy nhị phân
```cpp
int lca(int a, int b) {
    if (depth[a] < depth[b]) swap(a, b);
    a = kth(a, depth[a] - depth[b]);              // đưa về cùng độ sâu
    if (a == b) return a;
    for (int j = LOG - 1; j >= 0; j--)
        if (up[j][a] != up[j][b]) a = up[j][a], b = up[j][b];
    return up[0][a];
}
```
`O(n log n)` tiền xử lý, `O(log n)` mỗi truy vấn.

**Khoảng cách:** `dist(a, b) = depth[a] + depth[b] - 2·depth[lca]`. Thông tin trên đường đi (max cạnh, tổng) lưu song song trong bảng nhảy.

## 3. Euler tour
Ghi `tin[v]` khi vào và `tout[v]` khi ra (chỉ tăng bộ đếm khi vào). Cây con của `v` là **đoạn liên tiếp** `[tin[v], tout[v]]` ⇒ bài toán trên cây con thành bài toán trên đoạn:
- tổng cây con có cập nhật: BIT trên thứ tự `tin`;
- cộng cả cây con: BIT trên mảng hiệu;
- tổng đường từ gốc tới `v`: giá trị của `u` góp cho cả cây con của `u`.

**Euler tour đầy đủ** (ghi cả khi quay về): `lca(u, v)` là đỉnh nông nhất giữa lần xuất hiện đầu của `u` và `v` ⇒ LCA `O(1)` bằng bảng thưa.

## 4. Mảng hiệu trên cây
Cộng `x` lên mọi đỉnh trên đường `a → b`: `c[a] += x, c[b] += x, c[lca] -= x, c[cha(lca)] -= x`, sau đó cộng dồn từ lá lên gốc. Phiên bản trên cạnh: `c[lca] -= 2x`.

## Lỗi thường gặp
- `LOG` quá nhỏ (cần `2^LOG > n`).
- Gốc có `up[0][root] = root` (hoặc 0) — thống nhất để không truy cập ngoài mảng.
