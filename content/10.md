# DFS, BFS, BFS 0-1

## 1. Biểu diễn đồ thị
Danh sách kề: `vector<int> adj[N]`; với cạnh có trọng số `vector<pair<int,int>>`. Bộ nhớ `O(n + m)`.

## 2. DFS — duyệt theo chiều sâu
```cpp
void dfs(int u) {
    vis[u] = true;
    for (int v : adj[u]) if (!vis[v]) dfs(v);
}
```
Ứng dụng: đếm thành phần liên thông, tìm chu trình (gặp đỉnh đã thăm khác cha), tô màu hai phía, loang trên lưới (flood fill).
Với `n` lớn, có thể cài bằng ngăn xếp tự quản lý để tránh tràn ngăn xếp.

## 3. BFS — duyệt theo chiều rộng
```cpp
queue<int> q; dist.assign(n + 1, -1); dist[s] = 0; q.push(s);
while (!q.empty()) {
    int u = q.front(); q.pop();
    for (int v : adj[u]) if (dist[v] == -1) { dist[v] = dist[u] + 1; q.push(v); }
}
```
BFS thăm đỉnh theo thứ tự khoảng cách tăng dần ⇒ cho **đường đi ít cạnh nhất**.

- **BFS trên lưới:** mỗi ô là một đỉnh, 4 (hoặc 8) hướng: `dx[] = {1,-1,0,0}`, `dy[] = {0,0,1,-1}`.
- **BFS đa nguồn:** đưa mọi nguồn vào hàng đợi với khoảng cách 0 (lửa lan, khoảng cách tới ô 1 gần nhất).
- **BFS trạng thái:** đỉnh là `(vị trí, thông tin thêm)` — ví dụ tập chìa khoá dạng bitmask.

## 4. BFS 0-1
Trọng số chỉ là 0 hoặc 1: dùng `deque`, cạnh 0 đẩy vào **đầu**, cạnh 1 đẩy vào **cuối**. `O(n + m)`.
```cpp
deque<int> dq; d[s] = 0; dq.push_back(s);
while (!dq.empty()) {
    int u = dq.front(); dq.pop_front();
    for (auto [v, w] : adj[u]) if (d[u] + w < d[v]) {
        d[v] = d[u] + w;
        if (w == 0) dq.push_front(v); else dq.push_back(v);
    }
}
```
Ứng dụng: đảo chiều ít cung nhất, phá tường ít nhất, lưới mũi tên.

## Lỗi thường gặp
- Đánh dấu đã thăm **khi lấy ra** khỏi hàng đợi thay vì khi đẩy vào ⇒ một đỉnh bị đẩy nhiều lần.
- Quên kiểm tra biên khi đi trên lưới.
- Đồ thị vô hướng: nhớ thêm cạnh cả hai chiều.
