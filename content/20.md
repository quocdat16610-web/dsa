# Trie

## 1. Cấu trúc
Cây mà mỗi cạnh mang một ký tự; mỗi nút ứng với một **tiền tố**. Các xâu có chung tiền tố dùng chung đường đi.
```cpp
int nxt[MAXNODE][26], cnt[MAXNODE], endc[MAXNODE], nodes = 1;   // nút 0 là gốc
void insert(const string& s) {
    int u = 0;
    for (char ch : s) {
        int c = ch - 'a';
        if (!nxt[u][c]) nxt[u][c] = nodes++;
        u = nxt[u][c]; cnt[u]++;            // số xâu đi qua nút
    }
    endc[u]++;                              // số xâu kết thúc tại nút
}
```
Chèn/tìm `O(|s|)`. Số nút ≤ tổng độ dài các xâu + 1.

## 2. Ứng dụng trên xâu
- Đếm số từ có tiền tố `p`: đi theo `p`, đáp án `cnt[u]`.
- Kiểm tra danh bạ nhất quán, gợi ý tự động, tiền tố chung dài nhất.
- `Σ LCP` mọi cặp = `Σ C(cnt[u], 2)`.
- **Trie + QHĐ:** tách xâu thành các từ trong từ điển.
- Trie các hậu tố ⇒ số xâu con phân biệt (với `n` nhỏ).

## 3. Trie nhị phân và XOR
Chèn số dưới dạng xâu bit từ bit cao xuống. XOR lớn nhất với `x`: tham lam **ưu tiên đi nhánh có bit khác** bit của `x`.
```cpp
int maxXor(int x) {
    int u = 0, res = 0;
    for (int b = 29; b >= 0; b--) {
        int k = x >> b & 1;
        if (ch[u][k ^ 1]) { res |= 1 << b; u = ch[u][k ^ 1]; }
        else u = ch[u][k];
    }
    return res;
}
```
- Đoạn con có XOR lớn nhất: XOR tiền tố + trie.
- Đếm cặp có XOR < k: duyệt theo bit của `k`.
- Có xoá: lưu bộ đếm ở mỗi nút.

## 4. Aho-Corasick
Trie các mẫu + **liên kết hậu tố** (giống hàm tiền tố KMP nhưng trên cây), xây bằng BFS. Duyệt văn bản một lần để tìm mọi lần xuất hiện của mọi mẫu: `O(|t| + Σ|p|)`.

## Lỗi thường gặp
- Ước lượng sai số nút tối đa (`MAXNODE` = tổng độ dài + 1).
- Trie nhị phân: dùng đủ số bit (30 bit cho `< 2^30`, 31 bit nếu `k` có thể bằng `2^30`).
