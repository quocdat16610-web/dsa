# Cái túi (Knapsack), LIS, LCS

## 1. Cái túi 0/1
`dp[j]` = giá trị lớn nhất với tổng khối lượng ≤ `j`. Mỗi vật dùng tối đa một lần ⇒ duyệt `j` **giảm dần**:
```cpp
for (auto [w, v] : items)
    for (int j = W; j >= w; j--) dp[j] = max(dp[j], dp[j - w] + v);
```
- **Không giới hạn:** duyệt `j` **tăng dần**.
- **Giới hạn số lượng `k`:** tách thành gói `1, 2, 4, ..., phần còn lại` rồi làm 0/1.
- **Theo nhóm:** mỗi nhóm chọn tối đa một vật — tính `dp` mới từ `dp` cũ.
- **Khối lượng lớn, giá trị nhỏ:** đổi vai trò, `dp[v]` = khối lượng nhỏ nhất đạt giá trị `v`.

## 2. Dãy con tăng dài nhất (LIS)
`O(n²)`: `dp[i] = 1 + max(dp[j])` với `j < i, a_j < a_i`.

`O(n log n)`: `t[k]` = giá trị cuối nhỏ nhất của dãy tăng độ dài `k+1`.
```cpp
vector<int> t;
for (int x : a) {
    auto it = lower_bound(t.begin(), t.end(), x);   // upper_bound nếu cho phép bằng nhau
    if (it == t.end()) t.push_back(x); else *it = x;
}
// t.size() là độ dài LIS
```
Biến thể: phong bì lồng nhau (sắp xếp `w` tăng, `h` giảm), LCS của hai hoán vị, định lý Dilworth.

## 3. Xâu con chung dài nhất (LCS)
```
dp[i][j] = dp[i-1][j-1] + 1                 nếu a_i = b_j
         = max(dp[i-1][j], dp[i][j-1])      ngược lại
```
**Khoảng cách chỉnh sửa:** `dp[i][j] = min(dp[i-1][j] + 1, dp[i][j-1] + 1, dp[i-1][j-1] + (a_i ≠ b_j))`.
Dãy con đối xứng dài nhất = LCS(s, đảo(s)).

## 4. Tiết kiệm bộ nhớ
`dp[i]` chỉ phụ thuộc `dp[i-1]` ⇒ giữ hai hàng (hoặc một hàng với thứ tự duyệt hợp lý).

## Lỗi thường gặp
- Cái túi 0/1 duyệt `j` tăng dần (thành không giới hạn!).
- Nhầm `lower_bound`/`upper_bound` giữa tăng ngặt và không giảm.
