# Hash (băm xâu)

## 1. Hash đa thức
`H(s) = (s_0·B^(n-1) + s_1·B^(n-2) + ... + s_(n-1)) mod M`. Tính tiền tố:
```cpp
h[0] = 0; for (int i = 0; i < n; i++) h[i+1] = (h[i] * B + s[i]) % M;
pw[0] = 1; for (int i = 1; i <= n; i++) pw[i] = pw[i-1] * B % M;
long long get(int l, int r) { return ((h[r] - h[l] * pw[r - l]) % M + M) % M; }   // s[l..r)
```
Hai xâu con bằng nhau ⇒ hash bằng nhau. Ngược lại có thể **va chạm** với xác suất ~ `1/M` mỗi cặp.

## 2. Chống va chạm
- Dùng `M` lớn: `2^61 - 1` (nhân bằng `__int128`), hoặc **hai modulo** khác nhau.
- Chọn `B` ngẫu nhiên lúc chạy (chống test được thiết kế để phá hash).
- Không dùng `unsigned long long` tự tràn (mod `2^64`) — dễ bị phá bằng xâu Thue–Morse.

## 3. Ứng dụng
- So khớp xâu (Rabin–Karp), đếm số lần xuất hiện.
- So sánh xâu con `O(1)`; LCP hai hậu tố bằng tìm kiếm nhị phân `O(log n)` ⇒ so sánh thứ tự từ điển.
- Chu kỳ, biên: `p` là chu kỳ ⇔ `s[0..n-p) = s[p..n)`.
- **Tìm kiếm nhị phân + hash:** xâu con chung dài nhất, xâu lặp lại dài nhất.
- Xâu đối xứng: so hash xuôi với hash ngược.
- Hash 2D (ma trận), hash cây (mã của cây con = hàm của multiset mã con).

## 4. Các thuật toán chính xác (không va chạm)
- **KMP** (hàm tiền tố `π`), **Z-function**: so khớp `O(n + m)`, chu kỳ, biên.
- **Manacher:** mọi xâu con đối xứng `O(n)`.
```cpp
vector<int> z(n); for (int i = 1, l = 0, r = 0; i < n; i++) {
    if (i < r) z[i] = min(r - i, z[i - l]);
    while (i + z[i] < n && s[z[i]] == s[i + z[i]]) z[i]++;
    if (i + z[i] > r) l = i, r = i + z[i];
}
```

## Lỗi thường gặp
- Ký tự mã hoá bằng 0 (`'a' - 'a'`) làm `"a"` và `"aa"` cùng hash — cộng thêm 1.
- Quên `+ M` khi trừ trong modulo.
